Privacy Policy

Last updated: August 2026
Your images and PDFs never leave your device. Squish runs entirely in your browser. We don't collect, store, or transmit any file data.

How Squish works

Squish is a static, client-side web app. When you convert, combine, or compress a file, the work happens entirely inside your browser using the Canvas API and JavaScript libraries bundled with the app. Your files are never uploaded to a server, and no server ever sees their contents.

What data we collect

None about your files. Squish has no backend, no database, and no file storage. We do not read, log, or transmit the images or PDFs you process.

Analytics

Squish uses Umami, a self-hosted, cookieless analytics tool, to collect anonymous, aggregate usage statistics such as page views and referrers. This never includes file names, file contents, or any personally identifying information.

Local storage & offline support

Squish is installable as a Progressive Web App. It no longer caches its own code for offline use, so every visit loads the current version from the network; nothing you process is ever stored. Squish does not set tracking cookies.

Third-party libraries

Squish bundles pdf-lib, pdf.js, and JSZip directly into the app build. None of them are loaded from an external CDN at runtime, and none of them transmit your data anywhere.

Children's privacy

Squish does not knowingly collect any information from anyone, including children under 13.
